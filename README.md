# Nova Logger — руководство

Показывает мощность с Ophir Nova на компьютере, рисует график и пишет CSV для Origin. Arduino Nano измеряет напряжение аналогового выхода Nova, страница в браузере пересчитывает его в мощность.

## Состав

```
nova_logger/
├── nova_logger.html          ← страница: открыть двойным щелчком в Chrome или Edge
├── README.md                 ← это руководство
└── nova_logger/
    └── nova_logger.ino       ← прошивка Arduino (Arduino IDE требует папку с тем же именем)
```

## Подключение

```
Nova, аналоговый выход (джек 2.5 мм)
  кончик ── 1 кОм ──┬── A0   Arduino Nano ── USB ── компьютер
                    └ 100 нФ ── GND
  гильза ───────────────── GND
AREF: только 100 нФ на GND, больше ничего
```

## Первый запуск

1. **Прошить Arduino:** Arduino IDE → открыть `nova_logger/nova_logger.ino` → плата Arduino Nano → Загрузить. Один раз, дальше не нужно.
2. **Закрыть Serial Monitor** в Arduino IDE: пока он открыт, порт занят.
3. **Открыть `nova_logger.html`** двойным щелчком (Chrome или Edge; в других браузерах не работает).
4. **Подключить** (кнопка справа вверху) → выбрать порт Arduino. Через ~2 с внизу пойдут строки, статус «Подключено».

## На Nova

- **AUTO выключить**, range выбрать вручную: MENU → range → треугольниками.
- dBm не использовать.

## Работа со страницей

**Range** — должен совпадать с Nova.
1. Сначала переключить range **на Nova**.
2. Потом на странице: число (целое, как на дисплее Nova) + кнопка единиц W / mW / µW → **Enter** или **✓**.
3. **Esc** — отменить ввод.

Пока не нажат Enter, ввод — только черновик (пунктир), ничего не меняется. После Enter Arduino сбрасывает среднее, график начинается заново, 5 с горит «Переключите Nova на …». Range запоминается между запусками.

**Мощность** — крупное число в единицах текущего range, ниже доля шкалы.
- **Копировать:** иконка справа или **Ctrl+C** (когда ничего не выделено и курсор не в поле range). Копируется число без единиц, момент отмечается пунктиром на графике.

**График**
- **Шкала: Range** — от 0 до range (пунктир — полная шкала). **Auto** — по данным, для малых сигналов.
- **Время:** последние 30 с / 5 мин / всё.

**Запись в файл**
1. **Начать запись** → выбрать, куда сохранить CSV.
2. **Остановить** — файл закрыт. Следующая запись — новый файл.

На диск данные сбрасываются каждые 5 с, при сбое теряется не больше 5 с. Файл открывается в Origin без настроек:

| t | V | P | range | copy |
|---|---|---|---|---|
| с от начала записи | напряжение от Arduino, В | мощность, W | шкала, W | 1 — нажали копирование |

## Что означает

| Видно | Значит | Что делать |
|---|---|---|
| Число и полоска **красные**, «зашкал» | выход Nova упёрся в 1 В, мощность больше шкалы | увеличить range |
| Число **тусклое**, «нет данных» | строки не приходят дольше 1.5 с | проверить USB |
| Подсказка под range **оранжевая** | напоминание переключить Nova или ошибка ввода | прочитать подсказку |
| Прочерки вместо числа | не подключено или не задан range | подключить, ввести range |
| Внизу: `Arduino: 0.383803 V` | напряжение на A0 | можно сверить мультиметром |
| Внизу красный текст | ошибка: порт, файл, нет ответа Arduino | по тексту |

## Точность

- Держите сигнал **выше ~10% шкалы**: ниже заметна погрешность аналогового выхода Nova (±0.3% шкалы) и АЦП (±1 отсчёт ≈ 0.1% шкалы).
- Значение — среднее за последнюю секунду, отстаёт на ~0.5 с. Сравнивать с дисплеем Nova — на стоящем сигнале.
- Сверка: 115.82 µW на странице против 115.6 µW на Nova (шкала 300 µW), 0.2%.

## Константы прошивки (`nova_logger.ino`)

| Константа | Сейчас | Что задаёт |
|---|---|---|
| `VREF` | 1.115 | опора АЦП, В. Измерить мультиметром на AREF и вписать — главная калибровка |
| `PERIOD_MS` | 100 | период строк, мс. Не меньше ~30 (блок измерений 27 мс) |
| `N_ACC` | 256 | выборок АЦП в одном блоке |
| `SIZE` | 10 | окно скользящего среднего, блоков. Время усреднения = `SIZE × PERIOD_MS` |
| `DIGITS` | 6 | знаков после точки в напряжении |
| `AIN_CH` | 0 | вход АЦП (A0) |
| `SLEEP_US_PER_CONV` | 104 | время одного преобразования во сне, мкс — для коррекции `millis()` |
| `TEST_MILLIS` | 0 | 1 — режим проверки времени: вместо `V` выводит `T,millis,номер` |
| `TEST_LINES` | 1000 | сколько строк выводит тест |
| `CORRECT_MILLIS` | 1 | 0 — выключить коррекцию `millis()` (для сравнения в тесте) |
